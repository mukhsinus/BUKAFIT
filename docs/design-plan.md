# Buka FIT — Дизайн-план

> Фаза 8. Источник: `фаза8_редизайн_bukafit.md` (дизайн-директива).  
> Заменяет визуальный слой Фазы 1 целиком. Бизнес-логика (три действия, цены, sticky, лид → Telegram, флаги контента, NOINDEX) без изменений.  
> Отклонения от директивы считаются ошибкой.

---

## 1. Концепт

**Три решения**

1. **Сайт светлый.** Премиум вэлнес — светлый, тихий, с огромной типографикой и большими фото. Тёмными остаются только hero, фотоинтерлюдии и футер. Драматургия = светлая страница / тёмные фотоблоки.
2. **Карточек нет.** Ни одной: ни тарифов, ни услуг, ни FAQ. Вместо боксов — полноширинные строки с волосяными разделителями, фотоплитки без рамок, типографические списки.
3. **Один акцент — вода (`pool`).** Глубокий петрольно-бирюзовый. Всё остальное — нейтрали. Золото/латунь запрещены.

**Настроение:** архитектурный / fashion-журнал, не «тёмный фитнес с золотом».

**Конверсия:** цены и CTA читаются раньше декора; в прайс-листе цена — крупный tabular набор (не display-гарнитура для длинных сумм).

## 2. Палитра — ровно 6 токенов

| Токен | Hex | Роль |
|--------|------|------|
| `chalk` | `#F4F5F3` | Фон страницы (минеральный белый, холодный — не крем) |
| `steam` | `#FFFFFF` | Приподнятые поверхности, редко |
| `mineral` | `#DDE1DC` | Hover-заливка, разделители, неактивные состояния |
| `ink` | `#101418` | Текст, тёмные секции, футер, инверсная строка тарифа |
| `pool` | `#0D6E7C` | Единственный акцент: CTA, ссылки, активные состояния, живая точка |
| `pool-deep` | `#0A5460` | Hover акцента |

**Больше цветов вводить запрещено.**

**Контраст (проверять фактически)**

- На `chalk` и `mineral` текст только `ink`.
- На `ink` и `pool` текст только `chalk` / `steam`.
- Над фото — только белый текст и только поверх скрима: `linear-gradient` снизу от `rgba(16,20,24,.85)` до прозрачного, минимум 55% высоты плитки.
- Белый / светлый текст на `mineral` или `chalk` — запрещён.
- Волосяные линии: `mineral` 1px; на тёмном — `rgba(244,245,243,.14)`.
- `focus-visible`: обводка `pool` 2px + offset 2px.

**Обработка фото**

- Лёгкая деконтрастация, слегка холодный тон, `brightness(0.92)` под скримами.
- Без duotone и цветных фильтров.
- Пропорции: hero 16:9 (кроп по `100svh`), мозаика 3:2 и 4:5, галерея 4:5.
- Плейсхолдер: заливка `mineral`, mono-метка по центру; никогда не выше своей плитки и не пустой провал.

## 3. Типографика

### Display — **Geologica**

| | |
|--|--|
| **Почему** | Google Fonts, вариативный, кириллица (`cyrillic` + `cyrillic-ext`). |
| **Веса** | 500 / 600 |
| **Набор** | Tracking `-0.035em`, интерлиньяж `0.92–1.0`. **Sentence case, не капс.** Капслок только в mono-метках. |
| **Подключение** | `next/font/google` → `Geologica`, subsets: `latin`, `cyrillic`. |

Unbounded не использовать: слишком широкий, ломает длинные суммы.

### Body — **Onest**

| | |
|--|--|
| **Почему** | Кириллица есть; нейтральный гротеск. |
| **Веса** | 400 / 500, интерлиньяж 1.5 |
| **Подключение** | `next/font/google` → `Onest`, subsets: `latin`, `cyrillic`. |

### Utility — **JetBrains Mono**

| | |
|--|--|
| **Почему** | Кириллица есть; клуб 24/7 — цифры времени смысловой центр бренда. |
| **Набор** | 400/500, `uppercase`, tracking `+0.08em`, 11–13px. `font-variant-numeric: tabular-nums` на часах и числах. |
| **Где** | Eyebrow-метки, время, единицы («сум», «м²»), бейджи, подписи к фото. |
| **Подключение** | `next/font/google` → `JetBrains_Mono`, subsets: `latin`, `cyrillic`. |

Если гарнитура без кириллицы — замена только из: Golos Text, Onest, Inter Tight, PT Root UI, Commissioner; зафиксировать в отчёте.

### Fluid-шкала

| Роль | Размер |
|------|--------|
| Hero | `clamp(3rem, 9vw, 8.5rem)` / 0.92 / −0.035em / 600 |
| H2 | `clamp(2.25rem, 5vw, 4.5rem)` / 0.98 / −0.03em / 600 |
| H3 | `clamp(1.375rem, 2.2vw, 2rem)` |
| Price | `clamp(2.25rem, 4.5vw, 4rem)` / tabular-nums / 500 — **не display** для длинных сумм |
| Body | 17px (mobile 16px) / 1.5 |
| Body-lg | `clamp(1.125rem, 1.6vw, 1.5rem)` |
| Mono | 12px / 1.3 / uppercase / +0.08em |

## 4. Форма, сетка, пространство

| | |
|--|--|
| Радиусы | `0` везде. Исключение: пилюли `999px` только для mono-бейджей и чипов-фильтров. |
| Тени | Запрещены. `box-shadow` только для `focus-visible`. |
| Градиенты | Только скримы под текст на фото. Декоративных нет. |
| Сетка | 12 колонок, gutter 24px |
| Макс. ширина | 1440px |
| Поля | 64px desktop / 20px mobile |
| Текстовая колонка | максимум 62 символа |
| Вертикальный ритм | 8 / 12 / 16 / 24 / 40 / 64 / 96 / 128px |
| Отбивка секций | `96px` mobile / `128px` desktop — не больше |

Breakpoints ориентир: `sm` 480 · `md` 768 · `lg` 1024 · `xl` 1280 · проверка на 360 / 390 / 768 / 1024 / 1440.

**Композиция:** каждая секция отличается от соседней. Повтор схемы «eyebrow → капс-заголовок → подзаголовок → ссылка справа → сетка» запрещён.

## 5. Сигнатурный элемент

**Живое время + «сейчас в клубе» — только в hero.**

- Левый верх, mono: `ТАШКЕНТ · HH:MM · ОТКРЫТО` + пульсирующая точка `pool`. Время `Asia/Tashkent`.
- **Из хедера индикатор времени убрать** — не дублировать.
- Нижняя mono-полоса: `СЕЙЧАС В КЛУБЕ · …` из расписания; если занятий нет: `СЕЙЧАС · ТРЕНАЖЁРНЫЙ ЗАЛ ОТКРЫТ`.
- При `prefers-reduced-motion`: точка статична.

**Цены:** tabular-nums (mono/body), не Geologica; «СУМ» — mono меньшим кеглем на базовой линии.

## 7. Motion

| | |
|--|--|
| Свойства | Только `transform` и `opacity` |
| Длительности | 200 / 300 / 400ms |
| Easing | `cubic-bezier(0.22, 1, 0.36, 1)` |
| Reduced motion | Декор off → мгновенные конечные состояния |

- Hero load: stagger 80ms; строки из-под маски (`clip-path` + `translateY`).
- Scroll-reveal: opacity + `translateY` 12px, `once`, порог 15%, **один раз на секцию**.
- Count-up фактов: 900ms, once.
- Hover (не touch): заливка строк 200ms, стрелка +4px, фото mosaic `scale(1.03)` 300ms.
- Галерея: драг + inertia, snap.
- Page transition: 250ms fade в `template.tsx`.
- Пилюля дня: layout-анимация активного состояния.

**Запрещено:** параллакс, тени при hover, вращения, магнитные кнопки, анимация на каждом элементе, анимация акцентного цвета, marquee.

## 8. UI-принципы и запреты

- Кастомный UI, без шаблонного кита.
- Sentence case в display; caps только в mono.
- Кнопки называют действие; прямоугольные, радиус 0 (кроме пилюль-чипов).
- Один акцент `pool`; без золота/латуни/янтаря.
- Без карточек с бордерами/радиусами; без декоративных градиентов и glow.
- Без белого текста на светлом; без пустых провалов-плейсхолдеров.
- Без дубляжа индикатора времени / вордмарка / подписей на одном экране.
- Не более 6 цветов и 3 гарнитур.
- Соседние секции — разная композиция.
