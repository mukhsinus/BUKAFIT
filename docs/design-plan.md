## 1. Концепт

**Настроение:** ночное премиальное спорт-пространство — тёплый графит, свет сауны, блик воды бассейна. Не «спортзал из шаблона», не неон, не фиолетовые градиенты.

**Один главный визуальный тезис:** клуб не закрывается. Вся boldness — в сигнатуре «Открыто сейчас»; остальной UI сдержанный и дисциплинированный.

**Конверсия:** цены и CTA читаются раньше декора; на тарифах цифры — самый крупный текст карточки.

## 2. Палитра (именованные токены)

| Токен | Hex | Роль |
|--------|------|------|
| `graphite` | `#1A1816` | Базовый фон страницы (тёплый, не #000) |
| `graphite-elevated` | `#24211E` | Поверхности секций, sticky-бар, модалка |
| `smoke` | `#E8E4DF` | Основной текст |
| `smoke-muted` | `#A39E97` | Вторичный текст, подписи, мета |
| `brass` | `#C4A46A` | Акцент: CTA, цена, рамка «Выгодный выбор», пульс точки |
| `brass-hover` | `#D4B87E` | Hover акцента |
| `water` | `#6B8FA3` | Редкий вторичный оттенок (бассейн, чипы воды, ссылки-мелочи) |
| `line` | `#3A3530` | Разделители, бордеры без акцента |
| `danger` | `#C45C4A` | Ошибки формы (тёплый, не кислотный) |
| `success` | `#7A9E7E` | Успех отправки заявки |

**Правила применения**

- Фон: `graphite` / `graphite-elevated` (лёгкий вертикальный градиент или шум 2–3% opacity — атмосфера без «плоского чёрного»).
- Текст: `smoke` / `smoke-muted`.
- `water` — не больше ~10% акцентов на экране; не конкурирует с `brass`.
- Запрещено: кислотно-салатовый/вольтовый, фиолетовые градиенты, чисто-чёрный `#000`, чисто-белый `#FFF` как фон.

**Контраст на акценте (жёсткое правило WCAG)**

- На `brass`-кнопках и любых `brass`-подложках текст **только** `graphite` (`#1A1816`).
- `smoke` на `brass` **запрещён** — контраст ~1.9:1, провал WCAG AA.
- `focus-visible` на тёмном фоне: обводка `brass` 2px + `offset` 2px.

**Обработка будущих фото (токен стиля)**

- Лёгкий тёплый duotone: тени → `graphite`, света смещены к `brass` (~8–12% overlay).
- Затемнение снизу/слева под текст: градиент `graphite` 0→70% opacity.
- Единый `object-fit: cover`; слоты и пропорции — в `public/media/README.md` (Фаза 2+).

## 3. Типографика

### Display — **Unbounded** (вместо Bebas Neue)

| | |
|--|--|
| **Почему не Bebas Neue** | В Google Fonts / `next/font` только `latin` + `latin-ext`. Кириллицы нет → прямое нарушение жёсткого требования раздела 4. |
| **Почему Unbounded** | Есть `cyrillic` + `cyrillic-ext`; атлетичный condensed-характер; variable weight; выглядит премиальнее и реже «шаблонного зала», чем Oswald (Oswald — дефолт спорт-лендингов). |
| **Применение** | H1–H3, цифры цен, бейджи «24/7», крупные факты (2000 м²). Верхний регистр на hero и цифрах; tracking плотный (`letter-spacing: -0.02em`…`-0.04em`). |
| **Подключение** | `next/font/google` → `Unbounded`, subsets: `latin`, `cyrillic`. |

**Unbounded — дисциплина набора (обязательно)**

- Гарнитура очень широкая: display-заголовки **короткие** — 1–3 слова на строку на мобильном.
- Weight display: **500–700** (не тонкий light).
- Размеры только через `clamp()`; на **360px** обязательная проверка: заголовок не ломает сетку и не уезжает за край.
- Слова **не переносим** (`hyphens` off, без принудительного wrap посередине слова) — при нехватке места **уменьшаем кегль**, а не дробим слово.

### Body — **Manrope**

| | |
|--|--|
| **Почему** | Полная кириллица; нейтральный геометрический гротеск; хорошо читается на mobile; не спорит с Unbounded. Golos Text — запасной вариант, если клуб попросит более «локальный» тон. |
| **Применение** | UI, абзацы, навигация, форма, FAQ. Weights: 400 / 500 / 600. |
| **Подключение** | `next/font/google` → `Manrope`, subsets: `latin`, `cyrillic`. |

### Fluid-шкала (ориентир)

| Роль | Размер |
|------|--------|
| Display hero | `clamp(2.75rem, 8vw, 5.5rem)` |
| Section H2 | `clamp(1.75rem, 4vw, 2.75rem)` |
| Цена на карточке | `clamp(2rem, 5vw, 3rem)` — визуально доминирует карточку |
| Body | `clamp(1rem, 0.95rem + 0.3vw, 1.125rem)` |
| Small / meta | `0.875rem` |

Межстрочный: display ~1.05–1.1; body ~1.5–1.6.

## 4. Сетка и композиция

**Mobile-first (основной трафик).**

| | |
|--|--|
| Breakpoints | `sm` 480 · `md` 768 · `lg` 1024 · `xl` 1280 |
| Контентная колонка | `max-width: 72rem` (1152px), горизонтальные поля `clamp(1rem, 4vw, 2rem)` |
| Базовая колонка | 4 колонки (mobile) → 8 (md) → 12 (lg+) |
| gutter | 16px mobile / 24px desktop |
| Вертикальный ритм секций | `clamp(4rem, 10vw, 7.5rem)` между смысловыми блоками |

**Композиция главной (первый viewport = один тезис)**

1. Full-bleed media через компонент `HeroMedia` — край в край.
2. Поверх: бренд (слово/логотип как hero-сигнал), один value-headline, один сабтайтл с фактами, группа CTA (primary + Telegram), сигнатура «Открыто сейчас».
3. Без карточек, статов-полос и вторичного маркетинга в первом экране.
4. Второй экран — тарифы (достижимы одним скроллом / sticky «Абонементы»).

**HeroMedia (архитектура медиа)**

- Один компонент с двумя режимами: `video` (video + poster) и `image` (фото + медленный ken burns).
- Сейчас включён режим **`image`** (SVG/фото-заглушка). Видео подключается позже заменой одного пропа (`mode="video"` + `src`/`poster`), без переделки hero-разметки.

**Карточки** — только там, где есть интеракция (тариф, услуга, тренер). Hero без карточек. Рекомендованный тариф: акцентная рамка `brass`, без «стикерных» бейджей поверх медиа.

**Sticky**

- Mobile: нижний бар (safe-area) — «Абонементы» + «Записаться».
- Desktop: CTA в хедере, всегда в зоне видимости.

## 5. Сигнатурный элемент (обязателен)

**«● Открыто сейчас · HH:MM»**

- Места: хедер (компакт) + hero главной (крупнее).
- Время: реальное локальное `Asia/Tashkent`, обновление каждую минуту (или по `visibilitychange`).
- Пульсирующая точка цвета `brass` (opacity pulse на `transform`/`opacity` только).
- Копирайт фиксированный: «Открыто сейчас» (RU) / эквивалент UZ из словаря — клуб 24/7, статус не «закрыто».
- При `prefers-reduced-motion`: точка статична, без pulse.

Это единственное место, где дизайн намеренно «громкий»; остальной интерфейс — сдержанный.

## 6. Motion (краткий контракт для реализации)

| Эффект | Где | Правило |
|--------|-----|---------|
| Staggered reveal | Hero | Только transform/opacity, once |
| Scroll reveal | Секции | fade + rise 24px, `once: true` |
| Hover-lift | Карточки тарифов | Desktop; recommended — подсветка `brass` border |
| Magnetic buttons | Primary CTA | Desktop only |
| Count-up | 2000 м² и факты | По входу в viewport |
| Marquee | Направления тренировок | Пауза при reduced-motion |
| Page transition | `template.tsx` | ~300 ms |
| Reduced motion | Везде | Отключить всё декоративное |

## 7. UI-принципы (анти-шаблон)

- Кастомные компоненты, без узнаваемого «дефолтного» UI-кита.
- Sentence case в UI; display — upper где усиливает тезис.
- Кнопки называют действие: «Оставить заявку», «Выбрать абонемент», «Написать в Telegram».
- Акцент `brass` + вода `water` вместо неона/салатового/фиолетового.
- Первый экран = бренд + тезис + CTA + «Открыто сейчас», не «Добро пожаловать».
