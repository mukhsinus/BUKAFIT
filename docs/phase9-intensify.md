# ФАЗА 9 — усиление. Дизайн технически верен по спеку, но ощущается плоским, статичным и "из 2000-х". Ниже — точечные, но обязательные доработки. Это дополняет фазу 8, не отменяет её (радиусы, отсутствие рамок-карточек, светлая база — всё остаётся).

## 1. Живой градиент — источник "дорого" вместо второго цвета

Добавь ОДИН повторяющийся сигнатурный приём: медленно дышащее градиентное пятно (mesh/aurora), а не плоскую заливку.

- Новый токен: `--gradient-pool: radial-gradient(ellipse at 30% 20%, #0D6E7C 0%, transparent 50%), radial-gradient(ellipse at 80% 80%, #0A5460 0%, transparent 45%)` на фоне `ink`.
- Применить ТОЛЬКО в четырёх местах: фон hero (за фото/плейсхолдером, просвечивает по краям), инверсная строка тарифа "Год", фон футера, фон CTA-секции "Готов начать?".
- Анимация: `background-position` медленный дрейф 20-30s ease-in-out infinite alternate, `prefers-reduced-motion` — статичный кадр.
- Это не "третий цвет" в смысле новой палитры — это способ подать существующий акцент как живую текстуру, а не плоскую заливку. Больше двух градиентных пятен на экране не ставить.

## 2. Строка тарифа "Год" — убрать ощущение чёрной карточки

Причина, почему это выглядит как карточка: плоская чёрная заливка изолированного прямоугольника без текстуры и без движения.

- Фон строки — `--gradient-pool` вместо плоского `ink` (см. п.1), анимированный дрейф.
- При скролле во вьюпорт — не просто fade, а: фон-градиент проявляется отдельно от текста (текст reveal как у остальных строк, градиент fade-in 600ms с небольшой задержкой после).
- При hover — градиентные пятна ускоряют дрейф (переход на 8s), а не просто "заливка mineral" как у обычных строк.
- Пилюля "Выгодный выбор" — добавь тонкую постоянную пульсацию (opacity 0.85↔1, 2s, только если reduced-motion выключен).

## 3. Карта — убрать чертёж

Текущий вид (mono-текст на сетке) читается как техническая схема, а не как карта. Замени:

- Заливка `mineral`, БЕЗ сетки-паттерна.
- Крупная булавка-маркер по центру (простая SVG-капля, заливка `pool`, с лёгкой тенью-подсветкой под ней через тот же принцип градиента — не `box-shadow`, а мягкое радиальное пятно `pool` с низкой прозрачностью под маркером).
- При hover на плитку — маркер подпрыгивает (`translateY`, 2 итерации, ease-out), появляется подпись адреса.
- Кнопка "Показать карту" — по клику подгружает реальный Яндекс/Google embed. До этого момента макет должен выглядеть как осознанный дизайн, а не как заглушка-чертёж.

## 4. Motion — заметные моменты вместо фоновых микро-эффектов

Текущий motion технически есть, но не считывается — 12px fade и 4px hover не производят впечатления. Добавь несколько ощутимых акцентов, не размазывая эффекты по всему сайту:

- **Hero-заголовок**: смена приёма — построчный reveal через `clip-path: inset()` (маска открывается слева-направо, 700ms, stagger между строками 150ms) вместо простого fade+translateY. Это первое, что видит человек — должно чувствоваться.
- **Курсор-эффект на hero (desktop only)**: мягкое радиальное пятно `pool` с opacity 0.08, следующее за курсором с инерцией (lerp/spring, не мгновенно). Едва заметное, но живое — проверить, что не мешает читаемости текста.
- **Числа фактов**: сейчас count-up есть — усилить: во время подсчёта цифры чуть увеличены (scale 1.05→1) и слегка размыты в первый кадр (blur 2px→0), не только смена значения.
- **Переход между страницами**: сейчас fade 250ms — заменить на fade + едва заметный scale (0.99→1) на входящей странице, ощутимее держит внимание.
- **Строки прайса**: hover — добавить, помимо заливки mineral, лёгкий сдвиг всей строки `translateX(4px)` вместе со стрелкой (не только стрелка).
- **Фотоплитки мозаики (§4.4)**: hover уже есть (scale 1.03) — добавь параллакс-сдвиг внутреннего фото относительно контейнера на 4-6px в сторону курсора при движении мыши внутри плитки (desktop only, только когда фото реальное, не плейсхолдер).
- **Скролл-индикатор**: тонкая полоса `pool` 2px вверху страницы, растущая с прогрессом скролла — цепляет ощущение "живого" интерфейса на каждой странице, а не только на главной.
- **FAQ**: при раскрытии ответа — плюс не просто rotate(45deg) в крест, а сначала лёгкий scale-down/up (0.9→1) синхронно с rotate — ощутимее.

Правило: каждый эффект — либо ощутимый (можно описать словами, что человек увидит), либо не делать вообще. Пять невидимых микро-анимаций хуже одной заметной.

`prefers-reduced-motion`: все анимации из этого раздела — в статичное конечное состояние, включая градиентный дрейф.

## 5. Отчёт

Приложи скрин/видео-гиф hero (с курсор-эффектом), строки "Год" (с градиентом), карты (новый вид), и текстовое подтверждение по каждому пункту motion — что реализовано, что не влезло технически и почему.
